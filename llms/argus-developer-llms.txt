# ARGUS Developer

> ARGUS Developer is real estate development software from Altus Group for property
> developers, appraisers, consultants and financiers, covering development pro forma
> modeling, residual land value analysis, scenario comparison, cash flow forecasting and
> reporting across multi-stage development projects. It is part of the ARGUS suite and is
> delivered over the ARGUS Cloud platform.

Generated 2026-09-06 by the API Evangelist enrichment pipeline from this repository's
apis.yml and artifacts. Method: generated. Altus Group serves no llms.txt of its own
(https://www.altusgroup.com/llms.txt returned 404 on 2026-09-06).

## Important: no public API

ARGUS Developer does not publish an API, an OpenAPI or any other machine-readable
contract, an SDK, a developer portal or a sandbox. This was probed, not assumed:

- https://www.altusgroup.com/openapi.json — 404
- https://cloud.altusplatform.com/openapi.json — 200, but a single-page-app HTML shell;
  the same body is returned for a control path that cannot exist
- https://developer.altusgroup.com/, https://docs.altusgroup.com/,
  https://api.altusgroup.com/, https://developer.altusplatform.com/ — do not resolve
- https://api.argusenterprise.com/ — resolves, but the domain is parked and listed for
  sale on HugeDomains; it is NOT an Altus Group host. Any claim that ARGUS runs an API at
  api.argusenterprise.com is false.

The "ARGUS API" that Altus Group markets is a cloud integration gateway for ARGUS
Enterprise and other cloud-enabled ARGUS solutions, not an ARGUS Developer surface.
Its former product page (https://www.altusgroup.com/argus/products/argus-api/) now
redirects to https://www.altusgroup.com/argus/.

## Capabilities

- Development pro forma modeling for multi-stage projects (land, construction, sales)
- Residual land value analysis to determine maximum land bid prices
- Scenario analysis and side-by-side comparison
- Cash flow forecasting with budget-to-actual tracking
- Sensitivity analysis across costs, revenues, timing and interest rates
- Debt, equity and joint-venture funding structures
- 60+ reports for internal stakeholders and investor communication
- Cloud delivery over the ARGUS Cloud platform
